# Visual direction

The requested high-voltage energy-flow style is implemented as a carbon-black terminal with electric-lime accents, fine circuit borders, a pulsing engine core, orbit nodes, scanning light, and numeric monospace instrumentation. The main layout uses a persistent navigation rail, horizontal operational metrics, an asymmetric chart/engine monitor, and separate workflow lanes.

The collected `reference.png` is a visual inspiration image from image-search result 8, titled “Web3 Crypto Trading Dashboard — Neon Dark Mode UI Design” on Dribbble. It is not used as an application background or represented as original artwork. The interface, bolt mark, chart rendering, and energy-flow effects are implemented in source code. Token avatars use distinct initials rather than unverified token artwork.

The app uses DM Sans for readable UI text, Space Grotesk for hierarchy, and IBM Plex Mono for instrumentation. All ambient animation honors operating-system reduced-motion preferences, and energy flow can be disabled in interface settings.
