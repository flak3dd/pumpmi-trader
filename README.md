# pumpmi-trader

The paper-only pump.fun board engine is in [`pump-board-engine/`](pump-board-engine/).

**PAPER ONLY.** Nothing here signs a wallet or spends funds. `mode: live` is a stub that refuses to execute. Copy `pump-board-engine/.env.example` to a local `.env` if you need API placeholders, and do not commit `.env` or real keys.

Setup and the paper loop are in [`pump-board-engine/README.md`](pump-board-engine/README.md).
